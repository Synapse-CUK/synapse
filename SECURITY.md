# Security

If you find a security problem in Synapse, **don't open a public issue**. This includes ways to see another user's private data, gain a role you shouldn't have, or change someone else's data.

Report it privately through the repository's **Security** tab, using **Report a vulnerability**. If that isn't available, message the project lead directly.

Include what you did, what you could access, and the steps to repeat it. Please only test with QA accounts, and don't access real people's data.
