# Start Here

Welcome to Synapse. This page gets you from zero to your first finished task.

## 1. Get access

Ask Amal for each of these:

- [ ] **GitHub:** membership of the `Synapse-CUK` org (testers get the Triage role, developers get Write).
- [ ] **Linear:** an invite to the Synapse team.
- [ ] **Notion:** an invite to this workspace.
- [ ] **Convex:** an invite to the `synapse` project (developers only).
- [ ] **Clerk:** access to the Synapse application (developers only, if you'll touch sign-in).
- [ ] **Test accounts:** your own rows from the QA logins file, sent privately. Never share them in an issue or chat; the repo is public.

## 2. Understand the product (30 minutes)

1. Read **Product and Roles**.
2. Open https://synapse-cuk.vercel.app and sign in with your student account. If it asks for a code, enter `424242`.
3. Post an achievement, open the projects page, ask to join a team.
4. Sign in with your faculty account in a private window and verify your own student's achievement.

## 3. Understand the code (1 hour, developers)

1. Read **Architecture**, then skim **Data Model** and **Backend Reference**.
2. Clone the repo and follow **Local Development**.
3. Read `convex/_generated/ai/guidelines.md` before writing any Convex code. It overrides what you may know about Convex.
4. Run the checks: `npm run typecheck`, `npm run lint`, `npm test`.

## 4. Pick your first task

**This week (4 to 11 November) everyone works on Sprint 1.** Open **Sprint 1: Tags and Top Students**, join Team A or Team B, and read your team's spec.

After the sprint:

1. In Linear, filter the Synapse team by the label **Good first issue**, or ask Amal.
2. Assign it to yourself and move it to **In Progress**.
3. Follow **How We Work** for branches, commits and finishing.
